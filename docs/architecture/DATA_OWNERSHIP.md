# Data Ownership

Status: Phase 1 contract. Current location records where data concepts appear now; target location records intended ownership after migration.

Existing Ygrassil database tables do not automatically remain owned by Ygrassil. Most current Ygrassil tables are Office/Sales domain data because they describe leads, campaigns, opportunities, proposals, email conversations, suppression, and activity.

| organizations | Shared Core | core organization store | core admin flows | all products, agents | not yet explicit | `packages/core`, `packages/database` | yes | Needed for multi-tenant boundaries. |
